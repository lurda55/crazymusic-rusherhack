# CrazyMusic

RusherHack plugin by **lurda55**.

Now playing HUD (Spotify, Apple Music, YouTube...) with cover, progress bar and play/pause, next, previous.

## Install

1. Download `crazymusic-1.0.0.jar` from the [latest release](https://github.com/lurda55/crazymusic-rusherhack/releases/latest).
2. Put it in `.minecraft/rusherhack/plugins/`.
3. Start Minecraft 1.21.11 with RusherHack (plugins must be enabled: `-Drusherhack.enablePlugins=true`).

## Build

```
./gradlew build
```

The jar is in `build/libs/`.
